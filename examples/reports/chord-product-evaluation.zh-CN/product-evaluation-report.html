Skill Profile

技能在产品中的角色

app_profile 为运行时技能：触发方式为原生 provider 调用，执行 profile DAG，交付结构化画像，终止于画像完成，边界期望为无。技能用于生成用户数字画像并评估多头借贷风险、金融成熟度等，输出含叙述性总结与结构化指标。

Evaluation Design

为何这样设计实验

消融设计含 4 臂：enabled（启用）、invalid-replacement（无效替换）、related-precheck（相关预检替换）、removed（禁用）。每臂以 13 项验证准则评估触发、真实 LLM 执行、交付物、画像形状、证据一致性、边界与 fallback。任务输入与对照未保留，无法还原具体输入。

Skill Ablation Analysis

有 Skill 与无 Skill

enabled 臂触发、真实 LLM、交付物、边界均通过，仅画像证据一致性失败（叙述借贷=0 vs 指标 lending=1），说明技能能跑通但叙述与结构化指标脱节。removed 臂无触发、无 LLM、交付物缺失并走 fallback，符合禁用预期。invalid-replacement 同样走 fallback，说明替换未生效。

Skill Interaction Analysis

相关 Skill 的关系
