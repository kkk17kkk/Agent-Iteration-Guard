LightTable 产品评估报告

LightTable 的 recipe_planning Skill 消融评估共 5 次试验：enabled-1 与 related_precheck-1 通过，invalid_replacement-1 因超时基础设施错误，invalid_replacement-2 与 removed-1 失败。核心发现：Skill 启用时能正确触发原生 provider 调用并生成符合忌口约束的结构化菜谱；移除 Skill 后无原生调用、无触发事件，但仍有结构化输出（疑似走通用路径）；替换为无效实现时出现 fallback 且约束遵守失败。整体验证了 Skill 的触发与约束执行价值，但替换/移除场景的边界行为需进一步确认。

Final Assessment

最终评估

触发可靠性：enabled 与 related_precheck 均正确记录触发事件，removed 无触发符合预期，触发机制可靠。执行质量：启用时走原生 provider 且无 fallback，执行路径正确。输出质量：启用时方案排除忌口鸡蛋、结构完整；移除/替换时约束遵守失败，输出质量依赖 Skill。边界控制：SQLite 写边界在多数 arm 通过，invalid_replacement-1 因超时越界。总体有效性：Skill 对约束执行与原生路径有实质价值，但替换/移除场景暴露通用 fallback 路径可绕过契约，需加固。下一步：修复替换场景的 fallback 绕过、补充超时重试，并验证 removed 路径的通用输出是否应被拦截。

Skill Profile

技能在产品中的角色

recipe_planning 为声明式能力：触发条件是目标发起原生菜谱规划 provider 调用；执行由原生目标菜谱规划器使用声明 provider 完成；交付物为结构化膳食方案；终止条件为生成方案或发出 fallback 轨迹；边界期望为 none。enabled-1 与 related_precheck-1 完整满足全部 12 项验证标准，证明该 Skill 契约可被真实执行。

Evaluation Design

为何这样设计实验

消融设计覆盖四种干预：enabled（启用）、replacement（替换为无效/相关实现）、disabled（移除）。每 arm 以同一任务输入（目标 maintain、2 人、20 分钟预算、忌口鸡蛋）运行，由独立 verifier 按 12 项标准评分，含真实 LLM 执行、触发事件、交付物、约束遵守、SQLite 写边界与 fallback 检测。

Behavior Examples

保存证据支持的行为例子

有 Skill（enabled-1）：触发 recipe_planning_generated，原生 provider 调用，方案排除忌口鸡蛋，无 fallback。无 Skill（removed-1）：仅 recipe_planning_removed 事件，无原生调用、无触发，但仍有结构化输出与 shopping_suggestions，约束遵守失败。对比显示 Skill 是约束执行与原生路径的关键载体。

Skill Ablation Analysis

有 Skill 与无 Skill

移除 Skill 后（removed-1）无原生 provider 调用、无触发事件，但目标仍返回结构化方案，说明存在 Skill 之外的通用生成路径；该路径未遵守忌口约束。替换为无效实现（invalid_replacement-2）触发 fallback 且约束遵守失败，但 deliverable 仍通过，提示 fallback 路径可能绕过 Skill 契约。enabled 与 related_precheck 均通过，证明 Skill 本身可稳定工作。

Skill Interaction Analysis

相关 Skill 的关系

related_precheck-1 显示 Skill 与 precheck 事件（recipe_planning_precheck_completed）协同：precheck 完成后进入原生 provider 调用并生成方案，约束遵守通过。invalid_replacement-1 因超时中断，precheck/fallback 交互未完成，无法评估。Skill 与 precheck 的衔接在正常路径下有效，但异常路径的交互证据不足。

Limitations

限制与未解决项

invalid_replacement-1 因 TimeoutError 中断，其约束与边界结论不可用。removed-1 的通用输出路径来源未完全定位。任务输入、控制组与交互结论部分缺失，相关项按 unresolved 处理。通过试验仅证明声明契约，不构成发布决定。
